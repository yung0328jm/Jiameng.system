# 站內信後端推播 + 手機推播權限

讓用戶在收到站內信時，即使 App 關閉也能收到手機推播通知。

## 一、流程概覽

1. **App（Android）**：使用者登入後向 Firebase 註冊推播，取得 FCM token，寫入 Supabase 表 `push_tokens`。
2. **發送站內信時**：管理員回覆、管理員發給用戶、用戶發給用戶，都會呼叫後端 Edge Function `send-push`。
3. **後端**：依收件人帳號從 `push_tokens` 查 FCM token，用 Firebase FCM HTTP v1 API 發送推播。

## 二、Supabase 設定

### 1. 建立 push_tokens 表

在 Supabase Dashboard → SQL Editor 執行：

- 檔案：`docs/push_tokens.sql`  
或直接執行：

```sql
create table if not exists public.push_tokens (
  id uuid primary key default gen_random_uuid(),
  account text not null,
  token text not null,
  platform text not null default 'android',
  updated_at timestamptz not null default now(),
  unique(account, platform)
);
create index if not exists idx_push_tokens_account on public.push_tokens(account);
alter table public.push_tokens enable row level security;
-- 需建立允許 anon/authenticated 讀寫的 policy（見 push_tokens.sql）
```

### 2. 部署 Edge Function send-push

- 安裝 Supabase CLI 並登入：<https://supabase.com/docs/guides/cli>
- 在專案目錄執行：

```bash
supabase functions deploy send-push --no-verify-jwt
```

- 設定 Secrets（Supabase Dashboard → Edge Functions → send-push → Secrets，或 CLI）：

| Secret 名稱 | 說明 |
|------------|------|
| `FIREBASE_PROJECT_ID` | Firebase 專案 ID（例如 `your-project-id`） |
| `FIREBASE_SERVICE_ACCOUNT_JSON` | Firebase 服務帳戶 JSON **整份字串**（從 Firebase Console → 專案設定 → 服務帳戶 → 產生新的私密金鑰，複製整份 JSON 貼上） |

`SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY` 會由 Supabase 自動注入，不需手動設定。

## 三、Firebase 設定（Android）

1. 前往 [Firebase Console](https://console.firebase.google.com/)，建立或選擇專案。
2. 新增 Android App：套件名稱需與 `capacitor.config.json` 的 `appId` 一致（例如 `com.jiameng.app`）。
3. 下載 `google-services.json`，放到 **`android/app/`** 目錄下。
4. （可選）推播圖示：在 `android/app/src/main/AndroidManifest.xml` 的 `<application>` 內加入：
   ```xml
   <meta-data
     android:name="com.google.firebase.messaging.default_notification_icon"
     android:resource="@mipmap/ic_launcher"/>
   ```
   若無指定，系統會用 App 圖示（可能顯示為白塊）。

完成後重新建置 APK：

```bash
npm run build
npx cap sync android
```

再用 Android Studio 開啟 `android` 專案並建置／安裝。

## 四、驗證

1. 在手機上安裝 App、登入（需 Supabase 連線正常）。
2. 確認 Supabase 表 `push_tokens` 出現一筆該帳號的 token。
3. 用另一帳號或管理員發送站內信給該帳號。
4. 應收到「您有新的站內信」推播（App 在背景或關閉時也會收到）。

## 五、注意事項

- **僅 Android**：目前流程針對 Capacitor Android + FCM。iOS 需另外設定 APNs 與 Firebase iOS，並在 Xcode 啟用 Push Notifications capability。
- **權限**：Android 13+ 會詢問通知權限，使用者需允許才能收到推播。
- **Edge Function**：使用 `--no-verify-jwt` 時，請勿在未受信任的環境暴露可任意呼叫的 API；若僅由自家 App 呼叫且 Supabase anon key 已保護，一般可接受。

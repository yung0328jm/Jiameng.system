# 部署後功能不同步 — 快速修復

**現象**：管理帳號看得到手機註冊用戶，但待辦／排程／錢包等所有功能都不同步，重新整理也沒用。

**原因**：Supabase 裡只建了 `profiles`（登入用），還沒建 **`app_data`、`engineering_schedules`、`leave_applications`、`special_leave_quota`**，所以同步讀不到資料。

---

## 請立刻做（約 2 分鐘）

### 1. 在 Supabase 執行完整 schema

1. 登入 **Supabase** → 左側 **SQL Editor** → **New query**。
2. 開啟專案裡的 **`docs/supabase-schema.sql`**，**整份複製**貼到 SQL Editor。
3. 按 **Run**。

若出現「relation … is already in publication」：代表該表已在 Realtime，**可略過該行**，其餘照跑。

### 2. 確認 Realtime 有 app_data

左側 **Database** → **Replication**（或 **Publications**），確認 **supabase_realtime** 裡有：

- `app_data`
- `engineering_schedules`
- `leave_applications`
- `special_leave_quota`

若沒有，回 SQL Editor 單獨執行這四行（已存在會報錯，可略過）：

```sql
alter publication supabase_realtime add table public.app_data;
alter publication supabase_realtime add table public.engineering_schedules;
alter publication supabase_realtime add table public.leave_applications;
alter publication supabase_realtime add table public.special_leave_quota;
```

### 3. 手機與電腦都重新登入一次

兩邊都**登出**再**登入**，讓 `syncFromSupabase()` 再跑一次。之後新增的待辦／排程等應會寫入 Supabase 並在兩端同步顯示。

---

## 若仍不同步

- 在**電腦**開部署網址 → **F12 → Console**，看是否有 `[Sync] 從雲端載入失敗` 或紅色錯誤。
- 確認 **Vercel**（或你的主機）**Environment Variables** 有設 `VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`，且與本機 Supabase 專案一致。
